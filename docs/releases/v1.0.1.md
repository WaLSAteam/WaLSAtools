# WaLSAtools v1.0.1

This maintenance release fixes issues in the Python package while keeping the interactive guide and existing analysis interfaces.

- **Spectral analysis.** Corrects odd-length FFT frequency labels and restores complex coefficient output with NumPy 2. FFT randomisation applies the same preprocessing settings to the observed and shuffled inputs. Fixes short-record Welch settings, aligns the settings used in paired spectra and corrects several significance thresholds.
- **Wave analysis.** Corrects k–ω Fourier bin alignment and radial power averaging while retaining the original smooth filter weights on the corrected grid. Fixes wavelet reconstruction scaling, POD mode accounting and SPOD filtering. EMD and EEMD honour requested preprocessing or ensemble settings.
- **Installation.** Repairs the command-line entry point, includes the licence and notices in the distributions, and lets pip select dependencies for Python 3.11 or later.

Affected results can differ where a calculation was corrected. Historical FFT power scaling and the interactive quickstart are retained. See the [installation guide](../python/installation.md) or [report an issue on GitHub](https://github.com/WaLSAteam/WaLSAtools/issues).
